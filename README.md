# VM-Manager-Pro
VM-Manager Pro ist eine moderne, webbasierte Verwaltungsplattform für virtuelle Maschinen auf Basis von KVM/QEMU. Über eine zentrale, intuitive Weboberfläche lassen sich virtuelle Maschinen erstellen, konfigurieren, starten, überwachen und sichern – ganz ohne klassische Desktop-Verwaltungssoftware.
